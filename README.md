💬  Quote Generator

📌 About

The Python Quote Generator is a beginner-friendly project
that displays random motivational quotes to inspire users.

✨ Features

- Displays random motivational quotes
- Generates another quote on demand
- Allows users to continue or exit
- Simple and interactive interface
- Random quote selection

🛠️ Technologies Used

- Python
- Random Module

📚 Concepts Learned

- Lists
- While loops
- Conditional statements
- User input
- Random selection
- Break statement

🚀 Future Improvements

- Add quote categories like Motivation, Study, Success, and Life.
- Display quote authors.
- Save favourite quotes.
- Add a graphical user interface.
